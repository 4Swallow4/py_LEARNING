# 后续继续编辑

这个文件夹就是你的学习工作区。以后加笔记、改例子、做新工具，都写在这里。

## 1. 建议用 VS Code 打开整个文件夹

1. 打开 VS Code
2. 文件 → 打开文件夹
3. 选桌面上的 `Python入门学习指南`
4. 右侧就能同时改 markdown 和 `.py`

推荐安装扩展：

- Python（微软官方）
- Markdown Preview（看指南时 `Ctrl+Shift+V` 预览）

## 2. 怎么记笔记（不要改乱主文档结构）

主文档 `Python入门学习指南.md` 可以改，但建议：

- **自己的理解、踩坑、截图说明**：新建 `笔记/第X章-我的笔记.md`
- **想补充官方例子**：在对应 `示例代码/` 文件末尾追加，或新建 `示例代码/05b_dicts_extra.py`
- **完成的练习**：放 `练习场/我的解答/`，不要直接覆盖 `答案参考`

可以复制下面的笔记模板：

```markdown
# 第 X 章笔记

日期：

今天搞懂了：

仍然模糊：

我改过的代码：

下次要问的问题：
```

## 3. 文件命名约定

| 类型 | 命名 | 例子 |
| --- | --- | --- |
| 章节示例 | 两位数字前缀 | `08_functions.py` |
| 自己加的例子 | 同章号 + 字母 | `08b_default_args.py` |
| 小工具 | 英文小写+下划线 | `todo.py` |
| 练习 | 中文或英文都可以 | `ex03_word_count.py` |

数字前缀是为了资源管理器里按学习顺序排。
