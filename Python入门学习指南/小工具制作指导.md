# 小工具制作指导（实例向）

目标：把已经会的语法，收成「打开终端就能用」的脚本。  
四个成品都在 `小工具实例/`，全部只用标准库。

---

## 通用配方（每次都按这个写）

### 第 1 步：一句话定义工具

坏例子：「做一个很强的系统。」  
好例子：「给定长度，生成一串随机密码并打印。」

### 第 2 步：先在纸上画数据流

```
输入 → 读入/校验 → 计算 → 输出（打印或写文件）
```

如果要记住上次的结果（待办、配置），中间加「读文件 / 写文件」。

### 第 3 步：拆函数，不要全塞进一个 `if`

建议最少三个名字：

- `parse_args()` 或直接用 `argparse`
- `do_work(...)` 真正干活
- `main()` 串起来

### 第 4 步：路径不要写死盘符

```python
from pathlib import Path
ROOT = Path(__file__).resolve().parent.parent
DATA = ROOT / "数据样例"
```

把工具拷到别的位置，只要相对结构还在，就还能跑。

### 第 5 步：给人类看的帮助

```python
parser = argparse.ArgumentParser(description="一句话说明这个工具")
parser.add_argument("--length", type=int, default=12)
args = parser.parse_args()
```

用户输入 `py -3 工具.py -h` 应能看到用法。

### 第 6 步：坏输入要失败得明白

```python
if args.length < 4:
    raise SystemExit("长度至少 4")
```

`SystemExit` + 一句中文，比抛一堆 traceback 更像工具。

## 实例 1：密码生成器

文件：`小工具实例/password_generator.py`

**用到的语法：** `argparse`、`random`、`string`、函数、`if`。

**运行：**

```powershell
cd "$env:USERPROFILE\Desktop\Python入门学习指南"
py -3 .\小工具实例\password_generator.py
py -3 .\小工具实例\password_generator.py --length 20 --no-symbols
py -3 .\小工具实例\password_generator.py -h
```

**读代码时盯这几处：**

1. 字符池怎么拼：大小写 + 数字，可选符号。
2. 为什么先从每类里各抽一个再打乱——避免「全是字母」的弱密码。
3. `--length` 校验。

**建议你改的三件事（由易到难）：**

1. 增加 `--count 5`，一次打印 5 个密码。
2. 增加 `--no-digits`。
3. 把生成的密码追加写入 `练习场/passwords.txt`（注意：这是练习文件，别拿去存真密码）。

对应知识点：指南第 3、7、8、11、12 章。

## 实例 2：成绩 CSV 汇总

文件：`小工具实例/csv_summary.py`  
数据：`数据样例/sample_scores.csv`

**用到的语法：** `csv.DictReader`、字典嵌套、`statistics`、格式化输出。

**运行：**

```powershell
py -3 .\小工具实例\csv_summary.py
py -3 .\小工具实例\csv_summary.py --csv .\数据样例\sample_scores.csv
```

**读代码时盯这几处：**

1. 用 `defaultdict(list)` 按姓名归类分数。
2. 每个人算平均，再找出及格线以下的记录。
3. 表格用 `f"{name:<8}"` 对齐，只是为了好看。

**建议你改：**

1. 增加「按科目平均分」。
2. 把结果写到 `练习场/score_report.txt`。
3. 增加 `--min-score 60`，让及格线可调。

对应知识点：指南第 5、7、8、9 章。

## 实例 3：文件夹统计器

文件：`小工具实例/file_counter.py`

**用到的语法：** `pathlib.Path.rglob`、`Counter`、后缀名。

**运行：**

```powershell
py -3 .\小工具实例\file_counter.py
py -3 .\小工具实例\file_counter.py --path .
py -3 .\小工具实例\file_counter.py --path "$env:USERPROFILE\Desktop\py_LEARNING"
```

默认统计**本学习文件夹**，不会乱跑你的整个硬盘。  
加 `--path` 才能看别的目录。请不要把 `--path C:\` 这种整盘路径丢给它（会慢，也没必要）。

**建议你改：**

1. 增加「总字节数」，换算成 KB/MB。
2. 忽略 `__pycache__` 和 `.venv`。
3. 只显示数量 ≥ 2 的后缀。

对应知识点：指南第 4、7、9、12 章。

## 实例 4：命令行待办本

文件：`小工具实例/todo.py`  
数据：`数据样例/todo.json`

这是四个里面最接近「真工具」的一个：读改写同一份 JSON。

**运行：**

```powershell
py -3 .\小工具实例\todo.py list
py -3 .\小工具实例\todo.py add "明天把第 8 章函数跑完"
py -3 .\小工具实例\todo.py done 4
py -3 .\小工具实例\todo.py remove 1
py -3 .\小工具实例\todo.py list --all
```

**数据长什么样：**

```json
[
  {"id": 1, "text": "...", "done": false}
]
```

这就是「列表套字典」。指南第 5 章的嵌套字典在这里落地。

**建议你改：**

1. `list` 时显示序号更友好的格式：`[x] 1. 内容`。
2. 增加 `undone` 命令。
3. 增加 `search 关键字`。
4. 每条待办加 `"created": "2026-09-12"` 字段。

对应知识点：几乎全书，尤其第 5、8、9、10、11 章。

## 从零做一个第 5 个工具（作业）

题目：**单词频率统计**

一句话：读取一个 `.txt`，统计出现最多的 10 个单词。

最小实现步骤：

1. `argparse` 接收 `--file`，默认用 `数据样例/notes.txt`。
2. `read_text` 读入。
3. 用 `.lower()` 和去掉标点（可以先 `.replace("，", " ")`，或 `str.maketrans`）。
4. `split()` 得到单词列表。
5. `Counter(words).most_common(10)`。
6. 打印。

进阶：

- 把结果写成 CSV。
- 忽略长度 ≤ 1 的词。
- 做成和 `file_counter.py` 一样的风格。

参考答案见 `练习场/答案参考/ex05_wordfreq.py`（先自己写）。

## 怎样判断「我的工具写得像样」

对照清单：

- [ ] `py -3 工具.py -h` 有说明
- [ ] 正常路径能跑出结果
- [ ] 缺文件时有中文提示
- [ ] 没有用到的 `import`
- [ ] 函数名能读懂
- [ ] 不把真实秘密写进代码
- [ ] 你能向别人用 30 秒讲清楚它干什么
