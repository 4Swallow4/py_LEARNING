## 现在怎么跑

本机已检测到 `py` 启动器，默认 Python 3.14。在 PowerShell 或 VS Code 终端里：

```powershell
cd "$env:USERPROFILE\Desktop\Python入门学习指南"

py -3 .\示例代码\01_hello.py
py -3 .\示例代码\05_dicts.py
py -3 .\小工具实例\password_generator.py --length 16
py -3 .\小工具实例\csv_summary.py
py -3 .\小工具实例\file_counter.py
py -3 .\小工具实例\todo.py list
```

## 建议学习顺序

1. 打开 `Python入门学习指南.md`，按章节读。
2. 每读完一章，运行同编号的 `示例代码/xx_*.py`。
3. 到 `练习场/练习题.md` 自己写，卡壳再看 `答案参考`。
4. 第 10 章之后做小工具：先读指导，再改 4 个现成工具。
5. 有自己的想法，按 `后续编辑说明.md` 往这个文件夹里加文件。

## 和原来练习的关系

你在 `py_LEARNING\练习` 里已经写过：

- `print`、变量、`if/else`

NumPy 放到后期「用途方向」，入门阶段先把标准库写稳。
